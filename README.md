# Shard — Sharan S's portfolio

A chatbot-first portfolio. **the assistant**, Sharan's assistant, answers questions from a knowledge base of verified facts. Desktop visitors also get the Shard desktop and the 3D retro computer; phones get Shard Mobile, an Android-inspired shell.

```bash
node server.js   # http://localhost:3000 — offline mode until LLM_API_KEY is set
npm test
```
See [docs/ASSISTANT.md](docs/ASSISTANT.md) for the architecture, configuration, deployment, the knowledge base and the open TODOs.
