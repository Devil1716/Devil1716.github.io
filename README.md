# DevilOS Trinity Portfolio

Personal portfolio for Devil1716, featuring three interactive experiences:

- **Sketchbook Portfolio** — Hand-drawn, sketchbook-inspired portfolio view.
- **DevilOS** — Interactive retro desktop OS simulation.
- **3D Studio** — Interactive 3D workspace and retro computer showcase.

## Live Site

[https://devil1716.github.io](https://devil1716.github.io)

## Local Development

Run the local static server with Node.js:

```bash
node server.js
```
